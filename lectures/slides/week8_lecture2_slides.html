Quick Recall


Before we start — what’s the difference between:

# Version A
ggplot(data = daily_visits_loc,
       aes(x = restore_loc, y = daily_visits,
           fill = "blue")) +
    geom_col()
# Version B
ggplot(data = daily_visits_loc,
       aes(x = restore_loc, y = daily_visits)) +
    geom_col(fill = "blue")

Type your prediction in chat before we run either one.

The “Why Is It Salmon?” Moment


Version A produces salmon-colored bars with a legend that says “blue.”

Why?

Putting fill = "blue" inside aes() tells ggplot2 that "blue" is a variable in your data. ggplot2 creates a new column filled with the word “blue” and maps it to fill — using its default color for that category.

The fix: move fill outside of aes():

ggplot(data = daily_visits_loc,
       aes(x = restore_loc, y = daily_visits)) +
    geom_col(fill = "blue")

This is now a constant — all bars are blue.

The aes() Boundary — The Most Important Rule


Inside aes() → maps a variable to an aesthetic
The value changes per data point based on your data.

aes(fill = visitor_type)   # different color per visitor type ✓


Outside aes() → sets a constant for all data points

geom_col(fill = "blue")    # all bars are blue ✓

“If you want to map a variable onto a graph aesthetic, put it within aes(). If you want to update your plot base with a constant, add it directly to the relevant geom_ layer outside the aes() call.”

— NCEAS Learning Hub textbook

Mapping a Variable to Color


fill = visitor_type inside aes() — correct, because it’s a real column:

ggplot(data = daily_visits_loc,
       aes(x = restore_loc, y = daily_visits,
           fill = visitor_type)) +
    geom_col()

ggplot2 assigns a different color to each visitor type and adds a legend automatically.

That’s the Grammar of Graphics at work.

Labels with labs() + Flip the Axes


ggplot(data = daily_visits_loc,
       aes(y = restore_loc, x = daily_visits,
           fill = visitor_type)) +
    geom_col() +
    labs(
        x        = "Number of Visits",
        y        = "Restoration Location",
        fill     = "Type of Visitor",
        title    = "Total Visits to Delta Restoration Areas by Visitor Type",
        subtitle = "Sum of all visits during July 2017 and March 2018"
    ) +
    theme_bw()

Swapping x and y → horizontal bars → overlapping labels solved in one line.

Built-in Themes


ggplot2 ships with several complete themes. Try them with auto-complete:
type theme_ then Tab in RStudio.

theme_bw()       # white background, dark grid — textbook standard
theme_minimal()  # no background panel, just grid lines
theme_light()    # light gray grid, white background
theme_classic()  # no grid at all — publication classic

Fine-Tuning with theme()


theme() gives fine-grained control over every visual element.
⚠️ Must come after built-in themes — otherwise theme_bw() overrides your settings.

ggplot(data = daily_visits_loc,
       aes(y = restore_loc, x = daily_visits,
           fill = visitor_type)) +
    geom_col() +
    labs(x = "Number of Visits", y = "Restoration Location",
         fill = "Type of Visitor",
         title = "Total Visits to Delta Restoration Areas by Visitor Type") +
    theme_bw() +
    theme(
        legend.position = "bottom",
        axis.ticks.y    = element_blank()
    )

Save Your Theme as an Object


When you have a set of theme settings you like — save them once, use everywhere:

my_theme <- theme_bw(base_size = 16) +
    theme(
        legend.position = "bottom",
        axis.ticks.y    = element_blank()
    )
ggplot(data = daily_visits_loc,
       aes(y = restore_loc, x = daily_visits,
           fill = visitor_type)) +
    geom_col() +
    labs(x = "Number of Visits", y = "Restoration Location",
         fill = "Type of Visitor",
         title = "Total Visits to Delta Restoration Areas by Visitor Type",
         subtitle = "Sum of all visits during study period") +
    my_theme

base_size = 16 scales all text proportionally — change in one place.

Exercise 2: scale_x_continuous()


Predict what this line adds before running it:

scale_x_continuous(breaks = seq(0, 120, 20))

Then add expand = c(0, 0) — what changes?

scale_x_continuous(breaks = seq(0, 120, 20), expand = c(0, 0))
  • breaks = seq(0, 120, 20) → tick marks at 0, 20, 40, 60, 80, 100, 120
  • expand = c(0, 0) → removes the gap between bars and the axis line

These polish details matter for publication figures.

Reordering — Defeating Alphabetical Order


ggplot2 loves alphabetical order. That’s almost never the order you want.

forcats::fct_reorder() reorders a factor by another variable.

daily_visits_totals <- daily_visits_loc %>%
    group_by(restore_loc) %>%
    mutate(n = sum(daily_visits)) %>%
    ungroup() %>%
    mutate(restore_loc = fct_reorder(restore_loc, n))

levels(daily_visits_totals$restore_loc)   # no longer alphabetical!

To reverse — most visited at top — wrap n in desc():

mutate(restore_loc = fct_reorder(restore_loc, desc(n)))

Pattern: mutate + fct_reorder is one of the most frequent pre-plot steps.

Accessible Color with viridis


~1 in 12 men and 1 in 200 women have some form of color vision deficiency.

If your visualization relies on red-green contrast, a significant portion of your audience can’t read it.

The viridis package provides palettes that are:

  • Perceptually uniform
  • Accessible to the most common forms of color blindness
  • Print well in grayscale
ggplot(data = daily_visits_totals,
       aes(x = daily_visits, y = restore_loc,
           fill = visitor_type)) +
    geom_col() +
    scale_fill_viridis_d() +   # _d = discrete variable
    scale_x_continuous(breaks = seq(0, 120, 20), expand = c(0, 0)) +
    labs(x = "Number of Visits", y = "Restoration Location",
         fill = "Type of Visitor",
         title = "Total Visits to Delta Restoration Areas by Visitor Type",
         subtitle = "Sum of all visits during study period") +
    my_theme

Saving Plots with ggsave()


ggsave() saves the last plot you created — or any named plot object:

# Save the last plot rendered
ggsave("figures/visit_restore_site_delta.jpg",
       width = 12, height = 6, units = "in")

# Save a named object at publication resolution
ggsave("figures/visit_restore_site_delta.png",
       plot   = my_named_plot,
       width  = 12,
       height = 6,
       units  = "in",
       dpi    = 300)

ggsave() infers file format from the extension: .jpg, .png, .pdf, .svg all work.

Small Multiples with facet_wrap()


The ~variable syntax creates one panel per unique value of that variable.

This is Tufte’s small multiples — same chart repeated across subgroups.

facet_plot <- ggplot(data = daily_visits_totals,
       aes(x = visitor_type, y = daily_visits,
           fill = visitor_type)) +
    geom_col() +
    facet_wrap(~restore_loc,
               scales = "free_y",
               ncol   = 5,
               nrow   = 2) +
    scale_fill_viridis_d() +
    labs(x = "Type of Visitor", y = "Number of Visits",
         title = "Total Visits to Delta Restoration Areas") +
    theme_bw() +
    theme(legend.position = "bottom",
          axis.ticks.x    = element_blank(),
          axis.text.x     = element_blank())

ggsave("figures/visit_restore_site_facet.jpg",
       plot = facet_plot, width = 12, height = 8, units = "in")

facet_wrap() Key Arguments


Argument What it does
~variable One panel per unique value of variable
scales = "free_y" Each panel gets its own y-axis scale
scales = "free" Both axes free per panel
ncol = / nrow = Control grid layout


scales = "free_y" is important when sites have very different total counts — a shared scale would make small-count sites unreadable.


When to use faceting: across species, sites, treatments, time periods, experimental conditions…

From Static to Interactive


Two packages for interactive outputs — powerful when published to GitHub Pages (Week 11):


DT — interactive data tables
Sortable · searchable · paginated · built on the DataTables JavaScript library


leaflet — interactive maps
Pan · zoom · clickable markers · layerable tile sources


⚠️ These only render as interactive HTML — not in static PDFs or the RStudio viewer.
Render your Quarto document to HTML to see them.

Interactive Tables with DT


First, create a data frame of unique sampling locations using dplyr::distinct():

locations <- visits_long %>%
    distinct(restore_loc, .keep_all = TRUE) %>%
    select(restore_loc, latitude, longitude)

.keep_all = TRUE retains all columns (without it, only restore_loc is returned).

Then one function call creates a fully interactive table:

datatable(locations)

Readers can sort by any column, search, and paginate — far more useful than a static table for a monitoring dataset with many sites.

Interactive Maps with leaflet


leaflet uses %>% — not + like ggplot2. The ~ models columns to the map (similar to facet_wrap()).

leaflet(locations) %>%
    addTiles() %>%               # OpenStreetMap base layer
    addMarkers(
        lng   = ~longitude,
        lat   = ~latitude,
        popup = ~restore_loc     # clickable label
    )
# Circle markers with custom styling
leaflet(locations) %>%
    addTiles() %>%
    addCircleMarkers(
        lng         = ~longitude,
        lat         = ~latitude,
        popup       = ~restore_loc,
        radius      = 5,
        fillColor   = "salmon",
        fillOpacity = 1,
        stroke      = TRUE,
        weight      = 0.5,
        color       = "white",
        opacity     = 1
    )

Layering Tile Sources


You can layer USGS base maps using addWMSTiles() — the same layering logic as ggplot2 geoms:

leaflet(locations) %>%
    addWMSTiles(
        "https://basemap.nationalmap.gov/arcgis/services/USGSImageryTopo/MapServer/WmsServer",
        layers  = "0",
        options = WMSTileOptions(format = "image/png", transparent = TRUE)
    ) %>%
    addWMSTiles(
        "https://basemap.nationalmap.gov/arcgis/services/USGSHydroCached/MapServer/WmsServer",
        layers  = "0",
        options = WMSTileOptions(format = "image/png", transparent = TRUE)
    ) %>%
    addCircleMarkers(
        lng = ~longitude, lat = ~latitude, popup = ~restore_loc,
        radius = 5, fillColor = "salmon", fillOpacity = 1,
        stroke = TRUE, weight = 0.5, color = "white", opacity = 1
    )
