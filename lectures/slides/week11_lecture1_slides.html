The solution: GitHub Pages

What is GitHub Pages?

GitHub Pages is a free hosting service that turns a GitHub repository into a website.

  • Every repository can have its own site
  • The URL follows a predictable pattern
  • It updates every time you push to main
  • Works with any .html file — including Quarto output

The key insight: index.html is the default page. Whatever is in index.html is what visitors see first.

The URL pattern

GitHub follows a consistent naming convention:

https://{username}.github.io/{repo_name}/

Examples:

  • github.com → github.io
  • github.com/gretchen/training_gretchen becomes gretchen.github.io/training_gretchen/

The publishing workflow

There are four steps, and you already know all of them:

  1. Create index.qmd at the root of your repo
  2. Render it → produces index.html
  3. Commit and push both files to GitHub
  4. Activate GitHub Pages in Settings → Pages

After step 4, every future push automatically updates your site. No extra steps.

Why index.qmd?

index.html is a web convention — it’s the “front door.”

When a browser visits a folder (like your repo), it automatically looks for index.html and serves it.

  • Name must be exactly index (lowercase)
  • Operating systems handle case differently — get this right
  • The corresponding index.qmd is what you edit
  • Render it to get index.html

If you also have an index_files/ folder — commit that too.

Setting up: step by step

In RStudio:

  1. Open your training_{USERNAME} project
  2. File → New File → Quarto Document
  3. Title: “GitHub Pages Example”, format: HTML
  4. Save as index.qmd at the top level of the project
  5. Click Render → observe index.html appears
  6. Commit both index.qmd and index.html, push

On GitHub:

  1. Settings → Pages
  2. Branch: change from “None” → main, folder: root
  3. Click Save

Activating GitHub Pages

After clicking Save you’ll see:

“Your GitHub Pages site is currently being built from the main branch”

Wait 1–2 minutes, then visit your URL.

If you don’t see your page:

  • Check that index.html is committed and pushed
  • Check the URL exactly — trailing / matters
  • Hard refresh your browser (Cmd+Shift+R or Ctrl+Shift+R)

Linking multiple files

Your index.qmd can link to any other rendered .html file in your repo using standard Markdown syntax:

[Data wrangling and cleaning](scripts/data-wrangling-cleaning.html)

The path is relative — it starts from where index.qmd lives.

For this to work:

  • The .html file must exist (render first)
  • The .html file must be committed and pushed

What makes a good landing page?

Think about your audience.

For an advisor or committee:

  • Brief description of the project
  • Clear links to each analysis component
  • A note about the data source

For a collaborator:

  • What the repo contains
  • How to navigate the analyses
  • Status of work in progress

For future you:

  • Decision log entries integrated
  • Notes on what each file does

This is a real research skill

GitHub Pages isn’t a course exercise — researchers use this pattern to:

  • Share supplementary materials for publications
  • Host open data documentation
  • Create project websites for grants
  • Make interactive results accessible to non-R users

California spiny lobster (Panulirus interruptus)

  • Collected along the Santa Barbara Channel mainland coast
  • Santa Barbara Coastal Long-Term Ecological Research site
  • Tracks abundance, body size, and fishing pressure

Why does this species matter?

Panulirus interruptus: the basics

  • Spiny lobsters lack the large claws of their Atlantic cousins — they defend themselves with spines
  • Nocturnal foragers: urchins, mussels, snails, worms
  • Keystone predators in kelp forest ecosystems
  • Long-lived: can exceed 30 years
  • Commercially important: the largest US West Coast crustacean fishery by value

The measurement you’ll work with:

Carapace length (mm) The shell from the rostrum to the tail

Carapace length is a proxy for:

  • Age
  • Reproductive maturity
  • Ecological role

Methods:

The number and sizes of spiny lobster are recorded by divers in four 60 x 5 m (300 m2 total) lobster transects that are associated with each permanent SBC LTER kelp forest community survey transect.

Data on the abundance and size of the California spiny lobster, Panulirus interruptus,

  • collected annually in late summer

  • five sites (Arroyo Quemado, Carpinteria, Isla Vista, Mohawk and Naples)

Santa Barbara Coastal LTER, D. Reed, and R. Miller. 2022. SBC LTER: Reef: Abundance, size and fishing effort for California Spiny Lobster (Panulirus interruptus), ongoing since 2012 ver 8. Environmental Data Initiative. https://doi.org/10.6073/pasta/25aa371650a671bafad64dd25a39ee18 (Accessed 2026-04-13). ::: —

Why marine protected areas?

Two of the five study sites are MPAs since 2012:

  • IVEE — Isla Vista Reef
  • NAPL — Naples Reef

Three sites are not protected:

  • AQUE — Arroyo Quemado
  • CARP — Carpinteria
  • MOHK — Mohawk Reef

The central question: Does MPA protection change lobster abundance, size, and the relationship between fishing pressure and population structure?

Trap counts as a proxy for fishing pressure

The dataset has two components you’ll analyze separately:

Lobster abundance and size (Owner’s dataset)

  • Individual carapace measurements
  • Site, year, month

Commercial trap buoy counts (Collaborator’s dataset)

  • Number of trap floats observed
  • Proxy for fishing effort / pressure

Together: you can ask how fishing pressure relates to lobster population structure.

Connecting biology to your analysis

When you make analytical decisions in the activity, the biology matters:

  • Setting a size threshold at 70 mm — California spiny lobsters may take 5–9 years to reach reproductive maturity, maturing around 63.5–78.2 mm CL before they reach the legal harvesting size, ensuring they can breed at least once.
  • Filtering out NAPL — what are you losing ecologically?
  • The “high” fishing pressure threshold of ≥ 8 traps — what does that mean for the population?

Data science without domain knowledge produces answers that don’t mean anything.
