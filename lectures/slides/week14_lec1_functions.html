Why Functions? The DRY Principle

DRY: Don’t Repeat Yourself

“You should consider writing a function whenever you’ve copied
and pasted a block of code more than twice.”

— R for Data Science, Grolemund & Wickham

Every time you copy-paste:

  • You create a new opportunity for a typo
  • A formula change means finding every copy
  • Your future self (and reviewers) must read the same logic over and over

The Copy-Paste Trap

Imagine converting field temperature readings:

airtemps <- c(212, 30.3, 78, 32)

celsius1 <- (airtemps[1] - 32) * 5/9
celsius2 <- (airtemps[2] - 32) * 5/9
celsius3 <- (airtemps[3] - 32) * 5/9

Can you spot the problem before it becomes a manuscript error?
What if you had 200 field sites?

Anatomy of a Function

function_name <- function(argument1, argument2) {
  
  # body: what the function does
  result <- argument1 + argument2
  
  return(result)
}

Four parts every function has:

  • Name — verb that describes what it does
  • Arguments — inputs (nouns)
  • Body — the computation
  • Return value — what comes back out

Naming Functions Well

Best practices (R for Data Science):

  • Names should be verbs; arguments should be nouns
  • Use snake_case for multi-word names
  • Use a common prefix for a family of related functions
# Good names
fahr_to_celsius()
calc_gc_content()
calc_primer_tm()
calc_coulombic_efficiency()

# Less good
myfunction()
convert()
doTheThing()

🌡️ Example 1: Temperature Conversion

The ecological context

Field ecologists — botanists, watershed researchers, intertidal
biologists — routinely collect temperature data in Fahrenheit from
legacy sensors and need Celsius for analysis and publication.

Instead of repeating the formula for every site or time point,
we write it once and call it everywhere.

Building fahr_to_celsius()

fahr_to_celsius <- function(fahr) {
  celsius <- (fahr - 32) * 5/9
  return(celsius)
}

Test it on a single value, then a whole vector:

# Single value
fahr_to_celsius(212)    # expect 100

# Vector of field readings
airtemps <- c(212, 30.3, 78, 32)
fahr_to_celsius(airtemps)

🔋 Battery Chemistry Context

Coulombic Efficiency (CE) — a daily calculation

Every time a lithium-ion or other rechargeable battery completes
a charge–discharge cycle, researchers calculate CE to assess
how efficiently charge is stored and retrieved.

CE tells you: of all the charge I put in, how much came back out?

A Li-ion cell typically achieves >99% CE — but even a 99.0% vs.
99.96% difference predicts whether a cell survives 500 cycles
or fails at 200.

Researchers calculate this for every single cycle across
experiments with hundreds of cycles. This is exactly the
copy-paste trap.

Building calc_coulombic_efficiency()

#        discharge capacity
# CE = ─────────────────────── × 100
#         charge capacity

calc_coulombic_efficiency <- function(discharge_cap_mAh,
                                      charge_cap_mAh) {
  ce <- (discharge_cap_mAh / charge_cap_mAh) * 100
  return(ce)
}

Apply it across a full cycling dataset in one line:

cycling_data <- data.frame(
  cycle       = 1:5,
  charge_mAh  = c(3.01, 3.00, 2.99, 2.98, 2.97),
  discharge_mAh = c(2.98, 2.97, 2.96, 2.95, 2.94)
)

cycling_data$CE <- calc_coulombic_efficiency(
  cycling_data$discharge_mAh,
  cycling_data$charge_mAh
)

🧬 Molecular Biology Context

GC Content and Primer Design

Before every PCR experiment, molecular biologists calculate the
GC content of their primers — the percentage of bases that
are guanine (G) or cytosine (C).

Why it matters:
G–C base pairs form three hydrogen bonds; A–T pairs form two.
GC-rich primers bind more tightly to template DNA. GC content
directly determines:

  • Whether your primer will bind at your chosen temperature
  • The melting temperature (Tm) of the primer-template duplex
  • Whether your PCR will amplify the right product

Designing 20 primers means doing this calculation 20 times.
A function makes it instant and error-free.

GC Content and Melting Temperature

Wallace’s Rule for short oligonucleotides (14–20 bp):

Tm = 2°C × (A + T) + 4°C × (G + C)

GC pairs contribute 4°C each; AT pairs contribute 2°C each,
reflecting the difference in hydrogen bond strength.

Function Families: Common Prefixes

Notice what we’ve built naturally:

calc_gc_content()       # GC percentage from a sequence
calc_primer_tm()        # melting temperature from a sequence
calc_primer_stats()     # both, bundled as a list

calc_coulombic_efficiency()   # battery: CE from cap values

The calc_ prefix signals: “these are all calculation
functions” — easier to discover, autocomplete, and remember.

This is the function family pattern from R for Data Science.

Documenting Functions with roxygen2

A function with no documentation is a function your future self
cannot trust. Use roxygen2 comments — lines starting
with #' — immediately before your function definition.

#' Calculate GC content of a DNA sequence
#'
#' @param sequence Character string of nucleotide bases (A, T, G, C)
#'
#' @return Numeric: percentage of bases that are G or C
#' @export
#'
#' @examples
#' calc_gc_content("ATGCGCATTAGC")
#' calc_gc_content("AAAAAA")

calc_gc_content <- function(sequence) {
  sequence <- toupper(sequence)
  n_total  <- nchar(sequence)
  n_gc     <- nchar(gsub("[^GC]", "", sequence))
  return((n_gc / n_total) * 100)
}

roxygen2 Key Tags

Tag What it documents
#' Title One-line description of what the function does
@param name Each argument: name and what it expects
@return What the function gives back
@examples Working code examples
@export Makes function available if packaged

Documentation is part of the function — not an afterthought.
Write it while the code is fresh.

Coulombic Efficiency: Background

A rechargeable battery is charged by putting electrical charge into it, then discharged when charge is taken back out.

Charge capacity = how much charge goes into the battery Discharge capacity = how much charge comes back out

Both are measured in milliamp-hours (mAh).

Coulombic efficiency asks:

(discharge capacity / charge capacity) * 100

Values near 100% mean most stored charge was recovered. Lower values suggest some capacity was lost during the cycle.
